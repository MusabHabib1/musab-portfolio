How it runs

Seven steps, nothing missed

Every test follows the same flow, so parents get results on time.

Plan the scheduleAt the start of each month I fix every test: date, class, subject, chapters, marks, time and teacher.
Prepare the paperMade on the academy’s letterhead, matched to the scheduled chapters.
Conduct the testStatus changes from Scheduled to Conducted.
Check and enter marksTeachers check papers; I enter marks and mark the test Checked.
Results calculate themselvesTotals, percentages, grades, pass/fail and positions update instantly.
Result cards and position holdersEach student gets a printed card; the top 3 are listed automatically.
Print and shareAll cards print in one go; status becomes Result Ready.
